# 实施与验收

当前阶段：首版核心闭环已实现，验证证据和剩余项见 [构建与验证记录](build-status.md)。按以下里程碑递进，每阶段先完成可验证闭环，再扩展下一阶段。

## M1：应用与持久化

建立 TypeScript、TanStack Start / Router / Query、Node 本地入口、SQLite migration 和数据目录。完成项目增删改查、认证占位和错误契约。

退出条件：项目隔离与重启持久化通过；迁移失败不会清库；本地服务仅监听 loopback。对应 spec 验收 1。

## M2：React Flow 画布

实现自定义卡片、带标签连线、选择与视口、文字编辑、图片导入，以及领域操作、事务、自动保存、撤销重做。先验证手动操作再接 AI。

退出条件：spec 验收 2、5 的手动操作部分、12 通过；拖动只形成一次历史；删除节点后撤销能恢复关联；附件路径校验通过。

## M3：Codex 与 Grill

验证安装协议，完成 bridge、流式消息、右栏、底部 composer、范围冻结、AI 结构化操作和运行锁。补齐取消、冲突、重连及重试去重。

退出条件：spec 验收 3–6、9–11 通过；实际操作结果与对话描述一致；模型建议不会被自动记成已确认决策。

## M4：单份 Spec 与完整闭环

实现生成按钮、基础信息检查、草稿生成、手工编辑、过期提示、覆盖保护、恢复快照和 Markdown 导出。

退出条件：spec 验收 7–8 通过；以“设计这个白板工具”为真实场景走完想法、追问、决策、生成和继续更新流程。

## 验证矩阵

| 层级 | 重点 |
| --- | --- |
| 领域测试 | schema 校验、跨项目引用、批次原子性、逆操作、状态转换、修订冲突、幂等 |
| 存储集成 | migration、重启恢复、事务失败、附件引用和 spec 快照 |
| Bridge 集成 | 握手、实际完成、错误分类、取消与进程清理、协议不兼容 |
| 浏览器流程 | 创建项目、编辑画布、选择范围、grill、停止、生成/更新/恢复/导出 |
| 构建 | 类型检查、服务端构建、客户端构建、不泄漏 Node-only 模块 |
| 性能 | 200 张文本卡片、300 条连线的平移、缩放、选择和拖动；记录环境与基线 |

仅对关键行为及失效路径编写有意义的测试，不用镜像实现的测试代替实际交互验收。实测后再制定量化性能阈值。
